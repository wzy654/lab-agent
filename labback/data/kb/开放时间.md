# 实验室开放时间

## 通用开放时间

- 工作日（周一至周五）：08:00 ~ 22:00
- 周末及法定节假日：09:00 ~ 18:00
- 预约时段必须完全落在开放时间范围内，跨时段预约会被系统拒绝。

## 各实验室开放时间

每个实验室的开放时间以系统「实验室浏览」页面展示的「开放时间 ~ 关闭时间」为准，常见安排如下：

| 实验室 | 开放时间 | 说明 |
| --- | --- | --- |
| 计算机实验室 | 08:00 ~ 22:00 | 全年除节假日外开放 |
| 人工智能实验室 | 08:00 ~ 22:00 | 需预约后使用 |
| 电子电路实验室 | 08:30 ~ 21:30 | 涉及用电安全，晚间提前关闭 |
| 物理实验室 | 09:00 ~ 18:00 | 仅工作日开放 |

## 注意事项

- 开放时间可能因设备维护、课程占用、考试安排等临时调整，请以系统内最新信息为准。
- 关闭时间前请完成实验并整理好设备，按时离开实验室。
- 超出开放时间仍留在实验室的，将影响后续预约资格。
- 如需在非常规时段使用实验室，请联系管理员单独申请。
