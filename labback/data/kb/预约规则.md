# 实验室预约规则

## 基本流程

1. 用户登录系统后，进入「实验室浏览」页面选择实验室，可预约整个实验室或实验室内的某台设备。
2. 提交预约后，预约记录处于「待审核」状态，由管理员在「预约审核」页面审核。
3. 管理员审核通过后预约生效；拒绝则预约失效，不影响再次预约其他时段。

## 预约状态说明

| 状态 | 说明 |
| --- | --- |
| 待审核 | 已提交，等待管理员审核 |
| 已通过 | 审核通过，可按时使用实验室 |
| 已拒绝 | 管理员拒绝了该申请 |
| 已取消 | 用户主动取消，或超时未审核被系统自动取消 |

## 时间要求

- 只能预约当前时间之后的时间段，不能预约过去的时间。
- 预约结束时间必须晚于开始时间。
- 预约时段必须落在实验室的开放时间范围内（不能早于开放时间开始，不能晚于关闭时间结束）。

## 冲突规则

- 同一实验室同一时间段只能有一组有效预约（待审核或已通过都算占用）。
- 预约整个实验室时，该时段内不能有任何重叠的预约（包括其他人对单台设备的预约）。
- 预约某台设备时，不能与该设备自己的重叠预约冲突，也不能与整间实验室的预约冲突。
- 时间完全相同但属于不同实验室的预约互不影响。

## 取消与变更

- 只有「待审核」状态的预约可以由用户自行取消；已通过的预约如需变动，请联系管理员。
- 预约开始时间已过但仍处于待审核状态的，系统每分钟自动扫描并将其置为「已取消」。
- 如需修改预约时间，请取消原预约后重新提交。

## 审核说明

- 管理员只能审核「待审核」状态的预约，已处理的预约不能重复审核。
- 请尽量提前预约，为审核留出时间；寒暑假、考试周等特殊时段可能另行通知预约安排。
